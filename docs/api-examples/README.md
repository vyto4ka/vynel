# Примеры работы с API

Каждый пример проверен на живой панели: клиенты создавали и продлевали пользователей, приёмники принимали вебхуки и отвергали запросы с неверной подписью. Описание API — [API.md](../API.md).

Всем примерам нужны две переменные окружения:

```bash
export VYNEL_API=https://panel.example.com/<секретный путь>/api/v1   # адрес API со вкладки «API → Начало»
export VYNEL_TOKEN=vyn_...                                           # токен, показанный при создании
```

Приёмникам вебхуков — ещё секрет вебхука: `export VYNEL_WEBHOOK_SECRET=whsec_...`.

## Что в них общего

Клиенты повторяют запрос при сетевой ошибке, ответах `5xx` и `429` (с учётом `Retry-After`) и каждый запрос, который меняет данные, отправляют с `Idempotency-Key`, одним и тем же при всех повторах. Если ответ потерялся, продление не произойдёт дважды.

Приёмники читают сырое тело запроса, проверяют подпись `X-Vynel-Signature` за постоянное время и свежесть `X-Vynel-Timestamp`, пропускают уже обработанные `id` событий и отвечают `2xx` сразу.

## Быстрая проверка приёмника

1. Запустите приёмник: `VYNEL_WEBHOOK_SECRET=whsec_... python3 python/webhook_receiver.py 8000`.
2. В панели («API» → «Вебхуки») добавьте вебхук с адресом `http://127.0.0.1:8000/hook` и включите «Разрешить локальные адреса» (приёмник на том же сервере).
3. Нажмите «Проверить»: приёмник ответил `204`, значит подпись сошлась. Затем создайте пользователя (в панели или по API) — события придут в приёмник.

Для приёмника на другом сервере нужен адрес с HTTPS и, если он в локальной сети, то же «Разрешить локальные адреса».
