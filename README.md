**Своя панель для Xray за 5 минут: сервер, ноды, пользователи и подписки — одной командой.**

## ⚡ Установка

Нужен сервер на Ubuntu или Debian, root и **один домен** с A-записью на IP сервера. Запустите:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/vyto4ka/vynel/main/scripts/install.sh)
```

Откроется форма в терминале: **всё на одном сервере** (проще всего начать с него), только панель, только нода, обновить, защитить, удалить.
- Заполните пару полей: домен сервера подставится сам, если он уже есть, а DNS проверяется прямо при вводе.
- Отметьте галочки защиты.
- Закрыли форму на середине — при следующем запуске ответы вернутся.

Установщик поставит Xray и nginx, получит сертификат, включит файрвол и покажет **адрес панели и как в неё входить**: по паролю, по одноразовой ссылке или только через Telegram.

Дальше в панели: «Пользователи» → «+ Пользователь» → скопировать ссылку → открыть на телефоне → **KeqDroid** добавит подписку одной кнопкой.

> 📖 **[Наглядный гайд](https://raw.githack.com/vyto4ka/vynel/main/docs/guide.html)**: подготовка домена, проверка DNS, установка, проверки после, а затем работа с панелью — пользователи, профили, обновления, команды, Telegram-бот. Впишите свой домен, и он подставится во все команды.
>
> Пошагово, с отдельной панелью, нодами и решением проблем — **[INSTALL_GUIDE.md](docs/INSTALL_GUIDE.md)**.

## 💎 Почему vynel

| | |
|---|---|
| 🚀 **Одна команда — и всё работает** | Панель, Xray, сертификат, сайт-заглушка и подписки встают на **одном сервере с одним IP и одним доменом**. Без Docker, без правки nginx и certbot руками, без ручных JSON-конфигов. |
| 🧩 **Конфиг собирается сам** | Профиль выбирается из шаблона, а ключи Reality, shortId, SNI, пути и точки подключения генерируются **для каждой ноды автоматически**. Страну, флаг и название нода определяет сама при подключении. |
| 🛡 **Сервер не отличить от сайта** | Reality ведёт «чужих» на ваш собственный многостраничный сайт с настоящим сертификатом. На запрос по IP или с чужим именем nginx не отвечает и домен не выдаёт. Панель живёт на секретном пути, подписки неотличимы от обычных страниц, перебор токенов банится. |
| ⚡ **Три протокола на одном сервере** | VLESS Reality на TCP 443, **Hysteria2 на UDP 443**, XHTTP рядом — на том же домене и том же сертификате, который продлевается сам. |
| 🔁 **Изменения — без перезапусков** | Пользователи добавляются, продлеваются и отключаются на нодах **за секунды через API Xray**, без разрыва соединений у остальных. |
| 🔄 **Обновления из панели** | Панель сама видит новую версию. **«Обновить всё»** обновляет все ноды одновременно и панель последней: около минуты простоя, и всё поднимается само. Если новая версия не стартовала, возвращается прежняя. |
| 🎛 **Ноды под рукой** | Перезапустить Xray или nginx, отправить конфиг заново, перезапустить службу или весь сервер — из меню ноды, без SSH. |
| 🪶 **Лёгкая** | Один Go-бинарь (~40 МБ) и SQLite. Спокойно работает на 1 vCPU / 1 ГБ. Нода — тот же бинарь с агентом. |
| 🔐 **Надёжная связь панели и нод** | gRPC поверх взаимного TLS со своим CA. Ноды сами подключаются к панели, порт для них открыт только их адресам. Если связь пропала, статистика копится на ноде и доходит потом **без потерь**. |
| 🤖 **Telegram-бот из коробки** | Пользователи из чата, вход в панель **без пароля** одной кнопкой, бэкап каждую ночь, уведомления о недоступных нодах **без спама**. |
| 🧱 **Сервер выглядит как обычный сайт** | Файрвол открывает только то, что обслуживает vynel; сканеры портов блокируются на сутки; SSH — только по ключу и на другом порту, с проверкой, чтобы не запереть себя. |
| 🔑 **Вход под контролем** | Три режима: пароль, только одноразовая ссылка (пароля нет — подбирать нечего; можно ещё и случайный адрес панели на каждую сессию) или только Telegram Mini App. Сессия заканчивается после 5 минут бездействия, при смене IP и при закрытии вкладки. Бот пишет о каждом входе и убирает сообщение, когда сессия закончилась. |
| 🩺 **Понятно, что сломалось** | `vynel node diag` собирает отчёт о ноде (версии, сертификаты, порты, проверка сайта-заглушки) без ключей и UUID — его можно сразу отправить. |

## ✨ Возможности

### 🌐 Протоколы и маскировка

- **VLESS + Reality (self-steal)** — основной профиль: сервер выглядит как ваш сайт с настоящим сертификатом.
- **VLESS + XHTTP + REALITY** — трафик похож на обычные HTTP-запросы к сайту; режимы `stream-up` и `packet-up`, совместимая разметка для любых клиентов на ядре Xray.
- **VLESS + XHTTP через CDN** — запасной вход, когда IP серверов недоступны. Директивы nginx из инструкции к CDN вписываются в шаблон как есть.
- **Hysteria2** — QUIC на UDP 443 рядом с Reality, на том же сертификате; хорош на мобильных сетях и каналах с потерями.
- TLS-отпечаток (fingerprint) выбирается в профиле. Свои шаблоны пишутся прямо в панели — с подсветкой, проверкой и предпросмотром.

### 👥 Пользователи и подписки

- Срок, лимит трафика с автосбросом (день / неделя / месяц), лимит устройств по **HWID** — общий или свой у каждого, можно выключить конкретному пользователю.
- **Лимит IP одновременно** (по умолчанию 3) по данным всех нод: лишний адрес блокируется на нодах за секунды, а подписка с него показывает «лимит». Пинг серверов и IPv4+IPv6 одного телефона его не задевают.
- **Одна ссылка** на пользователя, своя или случайная: приложение само получает подходящий формат — ссылки, Clash/Mihomo, sing-box или Xray JSON.
- В браузере ссылка открывает **страницу подписки** в светлой или тёмной теме: QR-код, трафик, срок и кнопка «добавить в приложение». Вид, акцентный цвет, тексты, объявление и заголовки для приложений настраиваются в панели.
- Группы: кому какие серверы, профили или отдельные инбаунды. Шаблоны пользователей для быстрого создания.

### 🖥 Ноды

- Новый сервер — **одна команда**, которую выдаёт панель («Ноды» → «Добавить сервер»), и живой чеклист: связь, конфиг, DNS, сертификат.
- Действия из меню ноды: перезапуск Xray, nginx, службы, перезагрузка сервера, обновление.
- Несколько IP на сервере, вход и выход через разные адреса, автоматическая раскладка портов между Xray и nginx: если Reality и сайты делят порт 443, nginx разводит соединения по SNI.
- Сертификаты Let's Encrypt получает и продлевает сама нода; каждый новый конфиг nginx проверяется (`nginx -t`) до применения.
- BBR, fq и TCP Fast Open настраиваются сами.
- Пять встроенных сайтов-заглушек — облачное хранилище, дизайн-студия, документация, кофейня, блог: несколько страниц, адреса без `.html`, favicon, robots.txt и своя 404.

### 📊 Статистика

- Трафик за 24 часа / 7 / 30 / 90 дней со сравнением с прошлым периодом, онлайн, трафик и нагрузка по нодам, тепловая карта «когда пользуются», топ пользователей, приложения и платформы устройств.

### 🤖 Telegram-бот и бэкапы

- Создание, продление, отключение пользователей прямо из чата; карточка со ссылкой для отправки.
- **Вход в панель без пароля**: кнопка «Панель» открывает её прямо в Telegram, или одноразовая ссылка на минуту. Пароль можно выключить совсем.
- **Бэкап каждую ночь** в Telegram; новая панель поднимается из него одной командой, ноды переподключаются сами.
- Уведомления о недоступной ноде — **одно сообщение, которое обновляется**, а не спам.

### 🎨 Интерфейс

- Компоненты Material 3 на палитре в духе Catppuccin, бирюзовый и розовый акценты.
- Меню сворачивается в узкую панель с иконками; на телефоне выезжает сбоку.

## 🧭 Как это устроено

```
                    ┌────────────────────────── сервер ───────────────────────────┐
 KeqDroid ─────────►│ TCP :443  nginx: разводка по SNI, без расшифровки           │
                    │            ├─ имя Reality ─► Xray: VLESS Reality / XHTTP    │
                    │            │                 ├─ клиент с ключом ────────────► интернет
 браузер ──────────►│            │                 └─ всё остальное ─┐            │
                    │            └─ другие имена ────────────────────┤            │
                    │            nginx 127.0.0.1:8443 ◄──────────────┘            │
                    │             ├─ /s/<токен>  → подписка                       │
                    │             ├─ /<секрет>/  → веб-панель                     │
                    │             └─ остальное   → сайт-заглушка                  │
 KeqDroid ─────────►│ UDP :443  Xray: Hysteria2 (тот же сертификат)               │
                    │ TCP :80   nginx: сертификат Let's Encrypt                   │
                    │ vynel: панель, подписки, статистика, бот, агент ноды        │
                    └─────────────────────────────────────────────────────────────┘
                             ▲ gRPC + mTLS (:9443, открыт только адресам нод)
                             └──── другие ноды: vynel node + Xray + nginx
```

## 📋 Требования

| | |
|---|---|
| Система | Ubuntu 20.04+ или Debian 11+, `amd64` или `arm64` |
| Ресурсы | от 1 vCPU и 1 ГБ RAM |
| Сеть | публичный IP, свободные TCP 80 и 443 (для Hysteria2 — ещё UDP 443) |
| Домен | один домен с A-записью на сервер (для подписок и панели можно отдельные) |
| Клиент | **[KeqDroid](https://github.com/Lemonochka/keqdroid/releases/latest)** — Android, Windows, Linux |

## 🛠 Управление из терминала

```bash
vynel admin user add vasya                 # новый пользователь (срок и лимиты из шаблона)
vynel admin user show vasya                # ссылка подписки, трафик по нодам
vynel admin user extend vasya --months 1   # продлить
vynel admin node list                      # ноды: состояние, нагрузка, проблемы
vynel admin web                            # адрес и логин веб-панели
vynel admin web mode link                  # вход без пароля: только одноразовые ссылки (password | link | miniapp)
vynel update                               # обновить этот сервер (в фоне; --check — только сравнить версии)
vynel node diag > diag.txt                 # отчёт о ноде для поиска проблем
vynel firewall status                      # что открыто, сколько сканеров заблокировано
```

Обновлять удобнее из панели: баннер на дашборде → **«Обновить всё»**. Данные, ключи и пароль сохраняются.
