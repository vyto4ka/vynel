# vynel

**vynel** — панель и ноды для собственного VPN на [Xray](https://github.com/XTLS/Xray-core) (VLESS + Reality) и [Caddy](https://caddyserver.com/). Идея та же, что у Remnawave: серверы, профили, группы, пользователи, подписки, лимиты устройств. Отличия — установка одной командой и конфиг, который собирается сам: Reality-ключи, SNI, точки подключения и сертификаты руками настраивать не нужно.

> Статус: работает в режиме **all-in-one** (всё на одном сервере) и с дополнительными нодами. Управление — **веб-панель** (тёмная тема в цветах Мику) или терминал (`vynel admin`). Telegram-бот для админа: пользователи из чата, вход в панель одной кнопкой, бэкап каждый вечер, сообщения о недоступных нодах ([ROADMAP](docs/ROADMAP.md)).

## Быстрый старт

Нужны VPS с Ubuntu или Debian, root, свободные порты 80/443 и **один домен** с A-записью на IP сервера.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/vyto4ka/vynel/claude/magical-hamilton-9vnx7n/scripts/install.sh)
```

Откроется меню: **всё на одном сервере** (проще всего начать с этого), только панель, только VPN-нода, обновить, удалить. Скрипт задаст несколько вопросов (домен, email, название сервера, логин панели), установит всё и покажет итоговую таблицу с **адресом веб-панели, логином и паролем**. Дальше:

1. Откройте адрес панели (вида `https://ваш-домен/k9Qm2xT7aB3c/`) и войдите.
2. «Пользователи» → «+ Пользователь» → имя → «Создать».
3. Скопируйте ссылку подписки и откройте её на телефоне → кнопка «Happ» / «v2RayTun».

То же из терминала: `vynel admin user add vasya`, `vynel admin user show vasya`.

Пошагово, с объяснением каждого шага, отдельной панелью, нодами и решением проблем: **[docs/INSTALL_GUIDE.md](docs/INSTALL_GUIDE.md)**.

Ещё сервер — в панели «Ноды» → «+ Нода»: она выдаст одну команду для нового сервера.

## Как это устроено

```
                   ┌──────────────────────── сервер ─────────────────────────┐
 телефон (Happ) ──►│ :443  Xray (VLESS + Reality)                            │
                   │        ├─ VPN-клиент ──────────────────────────────► интернет
 браузер ─────────►│        └─ всё остальное ─► Caddy 127.0.0.1:8443         │
                   │                             ├─ /s/<токен> → подписка    │
                   │                             ├─ /<секрет>/ → веб-панель  │
                   │                             └─ остальное → сайт-заглушка│
                   │ :80   Caddy: сертификат Let's Encrypt                   │
                   │ vynel panel: веб, пользователи, статистика, подписки   │
                   └─────────────────────────────────────────────────────────┘
```

- **Reality self-steal.** Для всех, кроме VPN-клиентов, сервер выглядит как обычный сайт с настоящим сертификатом на своём домене.
- **Подписка.** Одна ссылка на пользователя. Приложение само получает нужный формат: ссылки, Clash/Mihomo, sing-box или Xray JSON. В браузере открывается страница с QR-кодом и кнопками приложений (KeqDroid, Happ, v2RayTun, Hiddify…). Её вид и заголовки для приложений (название, трафик, объявления, настройки Happ) настраиваются в панели.
- **Лимиты.** Срок, трафик и число устройств (HWID). Изменения применяются на сервере за секунды, без перезапуска.
- **Ноды.** Можно подключить ещё серверы. Каждый получит свой VLESS-инбаунд (`VLESS_NL`, `VLESS_DE`), а пользователи — доступ ко всем серверам их группы.
