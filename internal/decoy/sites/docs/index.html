Build data pipelines
with plain functions.

Stack is an open-source toolkit for small, testable data pipelines. Write steps as functions, run them locally, schedule them anywhere.

Get startedAPI reference

Install

One package, no daemon. Python 3.10 or newer.

Test

Every step is a function: test it with the tools you already use.

Run

Locally, in a container, or on any scheduler that runs a command.
