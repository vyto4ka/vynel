Getting started

Your first pipeline

Install the package:

pip install stack-pipelines

Describe the steps as functions and connect them:

from stack import step, pipeline

@step
def load(path): ...

@step
def clean(rows): ...

nightly = pipeline(load, clean)

Run it:

stack run nightly --path data/orders.csv

Next: read the guides on retries and scheduling.
