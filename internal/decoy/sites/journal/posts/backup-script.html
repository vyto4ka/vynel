A 40-line backup script I trust

Every night, rsync copies my home directory into a new dated folder on the backup disk, hard-linking files that did not change. Each snapshot looks complete but only new data takes space.

The part most scripts skip: once a month a second script restores a random folder and compares checksums. A backup you have never restored is a hope, not a backup.
